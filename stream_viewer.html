🎥 Meeting Stream Viewer

Enter the stream key to view the meeting stream

How to use:

  1. Create a bot using the API: POST /api/bots/
  2. Note the stream key from the bot creation response
  3. Enter the stream key above and click "Load Stream"
  4. The stream will appear once the bot joins the meeting

Stream URL format:

http://localhost:8000/hls/{stream_key}.m3u8

Example:

http://localhost:8000/hls/meeting-5.m3u8
